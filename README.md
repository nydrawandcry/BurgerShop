# Игра BurgerShop - учебный проект по компьютерной графике

Игра содержит в себе три уровня. Необходимо собирать бургеры по определенным рецептам. Время на приготовление одного бургера ограничено, но настраиваемо в настройках.

Управление осуществлено на WASD. Взять продукт - E. Выкинуть взятый продукт невозможно.

Упор в игре был не на код и реализацию, а на модельки, созданные вручную в Blender(речь идет про элементы бургера и коробки с ингредиентами).
